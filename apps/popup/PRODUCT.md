# Product

<!-- impeccable:product-schema 1 -->

## Platform

Web UI in a browser extension popup, built with React, TypeScript, Tailwind CSS, and Base UI.

## Product purpose

Minimal Twitter lets people customize X to reduce distractions and control its navigation, feed, appearance, and sharing controls.

## Operating context

Settings are changed in a compact browser popup and saved automatically to extension storage. The popup supports light and dark system appearance.

## Constraints

Preserve every existing feature, storage key, and save behavior. Keep controls keyboard accessible and usable within browser popup dimensions. Reuse installed dependencies and bundled fonts.

## Current request

Reorganize all features and redesign the popup. The user selected clean editorial styling: neutral surfaces, strong typography, and one accent.
